# 🎈 BouncyFinance — Personal Finance & Deals Logger

A modern, responsive, and animated personal finance tracker with spring physics, bouncy animations, expense logging, deals & discount savings tracker, monthly budget warnings, and savings goals.

---

## 🚀 How to Run the App

### Option 1: Double Click Launcher (Easiest)
Simply double-click [`run_app.bat`](file:///C:/Users/LENOVO/.gemini/antigravity/scratch/finance-logger-app/run_app.bat) in this folder.

### Option 2: Command Line
Open PowerShell / Command Prompt in this folder and run:
```powershell
python server.py
```

Then open your browser to: **`http://127.0.0.1:5000`**

---

## ✨ Features

- **⚡ Fast Transaction Logger**: Log income and expenses with categories, payment methods, recurring bills, and tags.
- **🏷️ Deals & Bargains Vault**: Track sales, promo codes, wishlist discounts, and calculate total money saved.
- **📊 Bouncy Visual Dashboard**: Animated count-up stat cards, Cash Flow trends, and category breakdown donuts.
- **🎯 Monthly Budgets & Goals**: Progress meters for spending limits with over-budget alerts and goal milestone deposits.
- **🎉 Bouncy Animations**: Spring physics, bouncy cards, hover scales, and celebration confetti on logs.
- **💾 Local SQLite Database**: All data is saved locally in `finance.db`. Includes CSV & JSON export/backup.
